# New

Repozytorium zawiera dwa projekty:

- **HabitFlow** (`index.html`) — jednoplikowa aplikacja webowa do śledzenia
  nawyków, z wbudowanym coachem AI (Benedykt) opartym o Claude API.
- **Jarvis** (`jarvis/`) — desktopowy asystent AI w stylu „Jarvisa": zespół
  agentów działających równolegle, głos z wake wordem „Hej Jarvis", research z
  rosnącą bazą wiedzy, pełne sterowanie komputerem i warstwa skanowania
  bezpieczeństwa, w futurystycznym interfejsie HUD. Szczegóły, uruchomienie i
  **ograniczenia** opisano w [`jarvis/README.md`](jarvis/README.md).
